# Loan Portfolio & Credit Risk Analysis

An exploratory analysis of consumer credit data using **SQL** and **Python**, focusing on repayment behaviour, credit exposure and default risk.

**Status:** 🚧 In Progress

---

## 📌 Project Overview

This project explores consumer credit data to identify patterns in borrower behaviour and historical defaults.

The aim is to apply SQL and Python to practical financial analysis, combining technical skills with an understanding of banking and credit risk.

## 🎯 Objectives

- Analyse credit exposure and repayment behaviour
- Investigate relationships between borrower characteristics and defaults
- Identify key credit risk indicators
- Visualise findings and communicate analytical insights

## 🛠️ Technologies

| Tool | Purpose |
|------|---------|
| SQL | Data exploration, filtering and aggregation |
| Python | Financial data analysis and visualisation (planned) |
| Pandas | Data manipulation (planned) |
| Matplotlib | Data visualisation (planned) |

## 📊 Dataset

**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)

**Dataset:** Default of Credit Card Clients

- 30,000 customer observations
- Credit limits, payment histories and repayment information
- Historical default outcomes
