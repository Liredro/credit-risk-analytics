Loan Portfolio & Credit Risk Analysis
An exploratory analysis of consumer credit data using SQL and Python.
Project Objectives
- Analyse credit exposure and repayment behaviour
- Investigate patterns in historical defaults
- Identify and visualise key credit risk indicators
Tools
- SQL — data exploration and aggregation
- Python — data analysis and visualisation (planned)
Dataset
UCI Machine Learning Repository — Default of Credit Card Clients (Taiwan, 2005).
